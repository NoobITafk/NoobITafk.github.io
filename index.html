FAQ

Перед стартом

Які задачі можна надсилати?

Web-застосунки, API та інтеграції, ботів, парсинг, автоматизацію, роботу з даними або іншу програмну задачу. Якщо задача не підходить — скажу прямо.

Чи обов’язковий дзвінок?

Ні. На старті краще текстом: ТЗ, уточнення, оцінка й домовленості можуть пройти через Telegram або email.

Який мінімальний бюджет?

Невеликі задачі розглядаю приблизно від $50. Для більших проєктів оцінка залежить від обсягу, ризиків та інтеграцій.

Скільки чекати відповіді?

Зазвичай відповідаю протягом 24 годин. Якщо для оцінки бракує даних, спочатку поставлю кілька уточнювальних питань.

Чому не весь код відкритий?

HRReserveSystem доступний публічно. Сильніші reusable-заготовки та приватні проєкти не відкриваю повністю, але можу показати їхню роботу через demo або відео.
